Jeu de l'ours

Un ours brun affamé, 60 secondes, et des individus qui s'enfuient. Combien vas-tu en attraper ?

Télécharger l'APK Android Jouer dans le navigateur

Installer sur Android

  1. Appuie sur « Télécharger l'APK Android ».
  2. Ouvre le fichier jeu-ours.apk une fois téléchargé.
  3. Si Android bloque l'installation, autorise l'installation d'applications inconnues pour ton navigateur (le jeu n'est pas sur le Play Store).
  4. Appuie sur « Installer », puis ouvre le jeu.

Comment jouer

  1. Pose le doigt sur l'écran : un joystick apparaît, glisse pour diriger l'ours.
  2. Touche les individus pour les manger. Ils fuient quand tu approches !
  3. Fais le meilleur score en 60 secondes.
Fait avec HTML5 Canvas et Capacitor.
